[Tilde](https://tildeformac.com/) is a native file manager and Finder replacement for Mac, with split views, tabs, custom sidebars, live groups, and custom properties.

This repository is the public place to submit **bug reports, feedback, feature requests, and suggestions** for Tilde. Share what's getting in your way, tell me what could work better, or suggest something you'd love to see.

## Share something

| What would you like to share? | Where to start |
| --- | --- |
| A bug, crash, or something that doesn't work as expected | [Report a bug](https://www.github.com/blazegreenhalgh/tilde-feedback/issues/new?template=bug_report.md) |
| A new feature, workflow idea, or improvement | [Request a feature](https://www.github.com/blazegreenhalgh/tilde-feedback/issues/new?template=feature_request.md) |
| General feedback, a question, or a small suggestion | [Share feedback](https://github.com/blazegreenhalgh/tilde-feedback/issues/new?title=Feedback%3A%20) |

## Before you post

- [Search existing issues](https://github.com/blazegreenhalgh/tilde-feedback/issues?q=is%3Aissue), including closed ones. If someone has already raised it, add a reaction or any extra details to their report.
- For bugs, include your Tilde version, macOS version, steps to reproduce, and what you expected to happen. Screenshots or a short recording help.
- For suggestions, describe the problem you're trying to solve and how the change would help your workflow.
- Keep each issue focused on one topic so it's easier to discuss and track.

Issues are public, so remove personal information from screenshots and logs before posting.
